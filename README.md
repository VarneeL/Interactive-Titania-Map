# Titania Map · GameHelper

Live site: https://varneel.github.io/Interactive-Titania-Map/

A Titania map with water and shrine pins you can tick off, hide by group, and add to.
Includes checklists, a pin editor, drawing on the map and a Steam player list.

Everything a visitor does is saved in their own browser (localStorage + IndexedDB).
Nobody else sees it. Settings → Download backup moves it to another browser or device.

Made with GameHelper.

## Files

- `index.html`, `styles.css`, `app.js` — the site (`app.js` is built from the files in `js/`)
- `starter/` — the Titania map image and the pins every new visitor starts with
